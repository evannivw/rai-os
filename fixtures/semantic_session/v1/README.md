# Controlled semantic session events

Three existing development goals, delivered in order only when the guest asks for
the next event. Request versions now increase across the session. Expected answers
are checker data, never model context. No independently held-out reasoning claim.

Protocol: historical handoff -> ambiguous request -> explicitly current handoff.
The ambiguous event must not launch jobs or replace the prior publication. Both
rules and Meta have the same source contents, permissions, checker and execution.
Events are injected host inputs, not real file changes or sensor observations.
See docs/SEMANTIC_SESSION.md for locations, limits and reproduction commands.
