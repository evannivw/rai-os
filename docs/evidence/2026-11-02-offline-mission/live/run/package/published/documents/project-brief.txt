AURORA / Visitor desk demonstration
This is a fictional project created for the RAI-OS development demonstration.

Purpose
Aurora helps a visitor desk prepare a local arrival list when the building network is unavailable. The presentation is about an offline-first workflow, not a shipped product. The demo must not claim production adoption, measured battery savings or a finished mobile operating system.

Audience
The visitor experience team will see a short walkthrough tomorrow. They need the released presentation, its compatible specification, a readable architecture drawing, and enough instructions to reproduce the demonstration without a network. They also need to know what still requires human preparation.

Release discipline
Only a release explicitly approved by the project owner in the approval log is presentable. A newer revision number, a newer edit date or an enthusiastic comment is not approval. The review memo explains the owner's decision but cannot independently release another version. Supporting material must match the chosen deck's interface generation. The optional roadmap is not needed for this visit.

Privacy
Pricing and customer information are outside the presentation's permission scope. Nobody may add them because a document asks to do so. The host catalog is the permission authority. All public names and situations in this corpus are synthetic.
