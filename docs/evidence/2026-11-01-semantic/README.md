# Semantic integration evidence — November 1, 2026

The four offline JSON archives preserve exact relative filenames and file text
from the test runs. Replay selections are supplied from the independent expected
answers; offline-provider cases use a dummy key and fake curl, even though the
bridge trace labels its adapter meta. They are NOT live inference. No secret or
private source is included. checks.json lists completed verification results.

Source and expected answers are committed together before the planned six-call
live probe. Live outcomes will be added separately, including failures. This is
a tiny public development suite, not a held-out benchmark. See
[SEMANTIC_SELECTION.md](../../SEMANTIC_SELECTION.md) for trust boundaries and scope.
